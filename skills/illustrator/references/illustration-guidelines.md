# Illustration Guidelines (starter — user to refine)

Basic starting rules. Replace/expand with Vincit's actual visual standards later.

- Keep diagrams simple — one concept per diagram, avoid overcrowding a single canvas.
- Consistent shape/color meaning across all diagrams in a project (e.g. blue = SAP standard object, orange = custom `Z*` object).
- Label everything — no unlabeled boxes or arrows.
- Prefer a single flow direction (top-to-bottom or left-to-right), not mixed within one diagram.
- Match the target document's brand/theme (Vincit colors/fonts) once that's supplied.
